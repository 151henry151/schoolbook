# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Fixed

- Find Debian games under `/usr/games`, require a specific GCompris activity, use software rendering on older graphics, and return to the tutor when the game exits. A separate system-Python return button works even when the daemon Python lacks Tk.
- Clear the CF-30's separate Panasonic firmware mute at kiosk startup, restoring speaker audio when ALSA and PipeWire already report unmuted.
- Load the current child UI on every kiosk start, including F11 recovery, instead of reusing an older cached screen whose speech controls do not match the backend. HTML entry pages are no longer cached; hashed assets remain cacheable.

### Added

- Remember videos after at least half their distinct content has played, excluding pauses and seeking. Give the tutor watch history and favor unseen videos for general topic requests, while allowing requested repeats.
- Expose the full GCompris 25.0.12 activity catalog, including falling-letter typing and both spoken-letter train activities, with offline English voice/resource setup.
- Resolve named albums by exact title and artist, verify the release tracks, and play them in album order. Failed or incomplete lookups no longer fall back to unrelated songs or narrated videos.
- Add a top-right Wi-Fi button on the child's home and talk screens, with network selection, connection status, refresh, and a closable settings panel.

## [0.10.0] - 2026-10-15

### Fixed

- Display parent-console session timestamps in Eastern time, with EST/EDT labels and correct handling of UTC timestamps from SQLite.
- Give the tutor the same finalized speech transcript shown on screen, instead of a separate audio interpretation; preserve names and numbers, recognize “watch a show about” requests, and show tutor text only when generated by the spoken response.
- Microphone resets replace the speech connection and discard old replies; Stop immediately silences playback and cancels the speech attempt until the child starts again.
- Keep stop/reset controls responsive during speech connection setup, audio sends, and video searches, and allow recovery after a lost connection.
- Process each Realtime tool call once and wait for the active response to finish before requesting the next reply.
- Recover the audio queue after a playback error instead of blocking later replies and microphone input.
- Ignore queued microphone input and speech recognition events during song or video playback.

### Added

- Mobile-friendly parent console hosted under `/schoolbook/`, with a separate reconnecting SSH tunnel, HTTPS cookie protections, conversation details, and clear offline/action errors.
- A visible pause/play button on the child’s song screen and persistent per-learner song history; general music requests play a shuffled queue of previously heard, still-approved songs.
- Show battery percentage, a charging symbol, and a low-battery color on the main screen; hide the indicator during videos and games.
- Let F11 restart the complete CF-30 kiosk session through Openbox, even when Chromium stops responding, without rebooting the laptop.
- OpenAI Realtime speech-to-speech live talk when `OPENAI_API_KEY` is set
- Connect to the GA Realtime API without the retired beta header
- Keep live replies on OpenAI speech and skip written choice menus for a child who cannot read yet
- Search and vet YouTube videos from live talk, then play only IDs that passed vetting
- Hands-free live talk: the microphone stays open, 1.5s of silence ends a turn, and speech interrupts the tutor
- AudioWorklet capture of 16 kHz PCM, a playback queue that drops cancelled turns, and Chromium mic auto-grant in kiosk
- Whisper STT via faster-whisper and espeak-ng TTS, used by default instead of fake providers
- `schoolbook` command that starts the daemon and a cage Chromium kiosk from one binary
- Launcher loads a gitignored `.env` for API keys without overwriting the process environment
- Kiosk launch falls back to Chromium without cage when the compositor is missing
- Find `schoolbook-session` next to the venv Python when it is not on PATH
- Disable Chromium GPU and use X11 on old graphics when `SCHOOLBOOK_DISABLE_GPU=1`
- Start Openbox under X11 so Chromium can paint the child UI on old Intel graphics
- Ignore a failed Wi-Fi probe so a missing NetworkManager does not put the tutor to rest
- Show a crossed microphone when capture fails instead of the listening ear
- Start a session D-Bus bus so PipeWire can keep the Pulse socket for Chromium
- Keep the X11 session shell so PipeWire is not hung up when Schoolbook starts
- Put PipeWire Pulse sockets outside `/run/user/0` so a root systemd user session cannot delete them
- Point Pulse clients at that socket from `~/.config/pulse/client.conf` so Chromium still finds the mic after it clears the environment
- Prefer the analog input over the speaker monitor so Chromium captures the microphone
- Remap the analog input to `schoolbook-mic` so Pulse keeps it as the default source
- Skip speaker-monitor capture devices when opening the microphone
- Disable browser echo cancellation so a quiet laptop microphone is not suppressed
- Raise analog capture gain and amplify quiet PCM before sending it to Realtime
- Boost only quiet microphone frames so a loud external mic is not clipped
- Leave room-noise frames unboosted so Realtime VAD can hear a new turn
- Return to listening and clear the input buffer when a turn transcribes as empty
- Turn speaker and Pulse output volume up to 100% on kiosk start
- Lower Realtime voice-activity threshold so a quiet microphone can start a turn
- Show the listening ear when the child taps the avatar even if the tutor already started speaking
- Ignore leftover tutor speech while the home screen is showing
- Pass Chromium `--no-sandbox` when the kiosk runs as root
- Cage uses the X11 backend on Xorg sessions instead of a missing Wayland nest
- Desktop X11/Wayland sessions skip nested cage and start Chromium kiosk directly
- Session-agent `kiosk` mode that launches localhost Chromium `--kiosk` and restarts it after a crash
- Parent End session writes a kiosk exit flag so cage returns to the previous session
- Child Wi-Fi picker that lists nearby networks and joins one with a password
- Parent menu Wi-Fi action for changing networks after unlock
- Kiosk boot helper that hides GRUB, prefers Debian 13, and starts Schoolbook without a login
