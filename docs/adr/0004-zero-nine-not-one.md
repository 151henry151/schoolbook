# ADR-0004: 0.9.0 is the software release; 1.0.0 waits for the pilot

Phase 9 in the design spec is two weeks of real use with a parent reading every transcript. That gate is not something the repository can satisfy. The tagged software release for the implemented daemon, session agent, child UI, and parent console is 0.9.0. Do not tag 1.0.0 until a parent is comfortable leaving the child with it.
