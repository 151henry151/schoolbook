# Schoolbook

Schoolbook has not been built yet. This repository currently holds the design specification only.

Schoolbook is a locked-down Linux learning environment where a child talks out loud with an AI tutor. The tutor teaches, shows things on a full-screen board, plays curated videos, and launches approved educational apps. Version 1 targets one six-year-old on a spare laptop, with the design written so it can later serve other ages, families, and Linux machines.

The machine boots straight into a kiosk session. Nothing else is reachable without the parent password. A parent console shows transcripts, progress, the tutor's video choices, and settings.

See [docs/design-spec.md](docs/design-spec.md) for the full design and implementation spec.
